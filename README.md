# MySQL VM lab 1

This repository contains troubleshooting training material, not production configuration.

The bootstrap script installs the distribution's `mysql-server` package: MySQL 8.4 on Ubuntu 26.04 LTS. Root authentication uses `caching_sha2_password`, which is supported by MySQL 8.0 and 8.4.

The lab user's password-expiration scenario and the existing database configuration are retained.
